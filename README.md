# Student Attendance Tracker

A React-based Student Attendance Tracker that helps manage student records and track attendance status through a simple dashboard.

## Features

- Add new students with unique student IDs.
- Prevent duplicate student IDs.
- View the complete student list.
- Search for students by name.
- Filter students based on attendance status.
- Mark students as Present or Absent.
- Delete student records.
- View attendance statistics.
- Persist student data using browser localStorage.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Browser localStorage

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Jishnu-proj/Attendance_Tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Attendance_Tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Data Persistence

Student records are stored in browser localStorage, so data remains available after refreshing the browser in the same browser storage environment.
